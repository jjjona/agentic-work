# 00-docs

This directory holds durable, reviewable artifacts for long-running work.
Prefer writing here over relying on chat history.

## Folders

- `00-docs/issues/`: issue briefs / problem statements.
- `00-docs/research/`: research writeups describing the current state.
- `00-docs/plans/`: implementation plans (phased, testable, resumable).
- `00-docs/progress/`: compact progress memos to resume work later.

Keep artifacts small, concrete, and easy to scan. Use ASCII filenames.
