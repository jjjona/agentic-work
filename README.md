This project contains an agentic workflow for use in brownfield projects, based on Dex Horthy's talk https://www.youtube.com/watch?v=rmvDxxNubIg

More details on the folder structure are in `agent-resources/README.md`.
The specific workflow can be found in `agent-resources/agent-instructions/README.md`.

The current structure is how I use it in my own projects, this way I can easily pull it in and don't have to mess about with folder structures.
